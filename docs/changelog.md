## [v0.25.0] - 2026-09-26

### Highlights

- New `providers` package: exchange an OAuth 2.0 authorization code for a normalized `OAuthUser` across Google and GitHub, for "Sign in with ..." login flows

### Added

- `providers.FetchGoogleUser` / `providers.FetchGitHubUser`: exchange an authorization code and return a provider-neutral `OAuthUser` (ID, email, name, avatar, access and refresh tokens). GitHub users with a private profile email fall back to the primary verified address from the emails endpoint (requires the `user:email` scope) ([`674e3b2`](https://github.com/grokify/goauth/commit/674e3b2))
- `providers.FetchGoogleUserWithToken` / `providers.FetchGitHubUserWithToken`: fetch provider-native profiles with an existing access token, using a client bounded by `providers.DefaultTimeout` ([`674e3b2`](https://github.com/grokify/goauth/commit/674e3b2))
- `providers.PrimaryVerifiedEmail` and `providers.ErrNoVerifiedEmail`: select a GitHub user's primary verified email, falling back to any verified email ([`674e3b2`](https://github.com/grokify/goauth/commit/674e3b2))
- `cmd/jwt_parse`: print a JWT's claims as JSON without verifying its signature, reading the token from the `JWT_PARSE` environment variable ([`8596ad9`](https://github.com/grokify/goauth/commit/8596ad9))
- `google/cmd/oauth2web` and `google/cmd/serviceaccount`: runnable examples that load credentials from a credentials set file and fetch the Google userinfo profile, printing only token metadata, never credentials or tokens ([`6660d4e`](https://github.com/grokify/goauth/commit/6660d4e))
